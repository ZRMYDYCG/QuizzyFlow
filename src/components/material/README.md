# Material 物料组件库

问卷编辑器使用的**通用表单**物料，已移除 NPS、疼痛量表、词云、图片选择、签名、上传等专项/其他表单类组件。

## 组件分组

| 分组 | 组件 |
|------|------|
| 基础输入 | 单行/多行、搜索、数字、密码、邮箱、电话、URL、@提及、OTP、标签 |
| 数值与评分 | 评分（Rate）、滑块、区间滑块 |
| 日期时间 | 日期、时间、周/月/年、区间 |
| 选择与下拉 | 单选、多选、分段、下拉、级联、树选择、自动完成 |

## 注册与使用

见 [index.ts](./index.ts) 中的 `componentConfigList` 与 `getComponentConfigByType`。
